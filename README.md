# Функциональное программирование. Работа 04

Швачкина Виктория, группа CSE6742onl. Дисциплина CSE6742 «Функциональное программирование», Satbayev University, 2026 год.

В репозитории находятся выполненные программные задания лекции № 4 «Функции высшего порядка» и лабораторной работы № 4 «Функции и неизменяемость данных», часть 2. Индивидуальное задание выполнено по варианту 3: анализ показаний счётчика электроэнергии.

## Состав

- `lecture/examples.py`: исходные примеры лекции, разбор типичных ошибок и дополнительные примеры `operator` и `functools`.
- `lecture/itertools_reference.py`: собственные примеры для 20 функций `itertools`.
- `lecture/coursework.py`: отчёт о расходах, композиция функций и JSON-подобное преобразование через `singledispatch`.
- `lab04/core/task00.py`–`task05.py`: задания 0–5 лабораторной работы.
- `lab04/variant03/task06.py`: 25 учебных показаний счётчика, соседние разности, расход по месяцам, пиковые месяцы и накопительный расход.
- `lab04/extra/extra.py`: скользящее окно, группировка через `reduce` и сравнение с `toolz`.
- `run_all.py`: последовательный запуск всех 72 практических пунктов с сохранением журналов.

Два отдельных локальных отчёта содержат объяснения, реальные скриншоты и письменные ответы на все 18 контрольных вопросов: 10 по лекции и 8 по лабораторной работе. Отчёты, скриншоты и исходные материалы преподавателя в этот публичный репозиторий не включены.

## Запуск

Требуется Python 3.12 или новее. Перейдите в корень скачанного репозитория, установите зависимость и выполните общий запуск:

```console
python -m pip install -r requirements.txt
python run_all.py
```

На Windows после установки зависимости можно также открыть `run_windows.cmd`. При необходимости используйте `py -3.12` вместо `python`.

Не добавляйте флаг `-O`: он отключает проверки `assert`. Скрипт `run_all.py` выводит результат каждого запуска, сохраняет журналы в `verification/runs` и возвращает ненулевой код завершения при ошибке. Зависимость `toolz==1.2.0` устанавливается через `pip`; её исходники в репозиторий не включены.

Отдельные примеры запуска:

```console
python lecture/examples.py 01
python lecture/itertools_reference.py groupby
python lecture/coursework.py transactions
python lab04/core/task02.py 4
python lab04/core/task05.py 7
python lab04/variant03/task06.py --part months
python lab04/extra/extra.py --part windows
```

## Проверки

При подготовке работы выполнены 72 из 72 успешных запусков. В программах проверяются обычные и граничные случаи, ошибки, ленивость итераторов и неизменность исходных данных. В лабораторной работе циклы `for` и `while` используются только внутри собственных реализаций `my_map`, `my_filter` и `my_reduce`.

В задании 3 время измеряется на 1 000 000 элементов с тремя повторами. Дополнительное задание сравнивает значения и время со стандартными реализациями `toolz`. Повторное измерение может дать другие секунды; результаты зависят от компьютера и нагрузки. Файл `lab04/core/benchmark_operator.json` создаётся при запуске задания 3.

Код отформатирован и проверен Ruff 0.17.1 по правилам E4, E7, E9, F и I. Настройки сохранены в `pyproject.toml`.

Показания счётчика, расходы и валютные курсы являются учебными данными. Курсы не описывают рынок, а показания не относятся к реальному прибору.
